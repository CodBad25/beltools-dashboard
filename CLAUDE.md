# BelTools Dashboard v2

## Vision

Tableau de bord enseignant avec 2 modes :
- Mode personnel : configuration des widgets
- Mode classe projetée : affichage sans barres d'outils

## Widgets prévus

- Minuteur (compte à rebours)
- QR code (généré dynamiquement)
- Tirage au sort (élèves/groupes)
- Feu tricolore (retour d'attention)
- Zone de texte libre
- Fond d'écran personnalisable

## Inspiration

[Digiscreen](https://codeberg.org/ladigitale/digiscreen) — Vue.js, AGPL-3.0

## Rôle futur

Remplacera la v1 du portail sur beltools.fr
